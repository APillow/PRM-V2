# PRM Cloud Starter

Cloud-only Next.js + Prisma + Neon starter for your Personal Relationship Manager MVP.

## Deploy
1) Create a Neon database and copy the connection string.
2) Create a GitHub repo and upload these files (keep folders). 
3) In Vercel: Import the repo and set env vars `DATABASE_URL` and `PRM_WRITE_SECRET`.
4) Deploy, then open `/activities`.
